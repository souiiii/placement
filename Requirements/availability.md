# Availability & Scheduling Constraints — 10 to 16 September 2026

## 1. Planning Window

The planner covers **10 September 2026 through 16 September 2026 inclusive**.

Important dates:

- **17 September 2026:** LSEG interview.
- **18 September 2026:** midsemester examinations begin.

All major LSEG preparation should be substantially complete by the night of **16 September**.

---

## 2. Daily Active Window

The planner may schedule preparation only within:

- **Start:** 9:00 AM
- **End:** 10:30 PM

Do not schedule preparation before 9:00 AM or after 10:30 PM.

The active day should still contain realistic rest/buffer periods. The presence of an open timeslot does not mean it must be filled with study.

---

## 3. Protected Daily Meal Blocks

These are fixed and must be labelled explicitly in the calendar.

### Lunch

- **1:00 PM–2:00 PM**

### Dinner

- **7:30 PM–8:30 PM**

Do not place study, interview practice, class replacement work, or other preparation inside these meal blocks.

---

## 4. Rest / Buffer Requirement

The planner must include realistic rest/buffer periods during the day.

These blocks are not intended as hidden study time.

They should be:

- clearly labelled;
- placed where they help prevent cognitive overload;
- long enough to be meaningful;
- balanced against the limited preparation window.

Codex should decide the exact locations and durations based on the surrounding workload.

---

## 5. Daily Midsem Self-Study Requirement

This is a hard scheduling constraint:

> **At least one genuine midsem self-study block must be scheduled every day from 10 September through 16 September.**

A college class does **not** count as a midsem study block.

Even on a day when the user attends CV, EPQ, RecSys, or IWT class, a separate self-study midsem block is still required.

---

## 6. Class Attendance Philosophy

The user is intentionally sacrificing most college class time during this week to maximize LSEG preparation.

However, the planner should aim for approximately:

> **20% attendance in each subject that is actually running during this period.**

Attendance should be counted using whole classes where practical.

The planner should choose which optional classes to attend based on which choices cause the **least disruption to preparation**.

Class attendance is only an attendance constraint.

> **Class time must not be counted as study/preparation time.**

---

## 7. Subjects Whose Classes Actually Matter

During this planning window, the attendance-relevant subjects are:

- IWT
- Computer Vision
- Recommendation Systems
- EPQ

The following classes should be treated as **not happening** and should not reserve time:

- Blockchain
- EMC
- TW

If the source timetable contains Blockchain, EMC, or TW entries, ignore them for scheduling purposes.

---

## 8. Mandatory Class

### Monday IWT Lab

The **Monday IWT Lab is mandatory**.

Codex must preserve this class even if another preparation block would otherwise fit there.

This mandatory lab also contributes toward the desired IWT attendance target.

---

## 9. Friday Namaz

On **Friday, 11 September 2026**, the following period is completely unavailable:

- **12:30 PM–3:00 PM**

This time is reserved for **namaz**.

It must be explicitly labelled in the final planner.

No study, class replacement work, mock, practice, revision, or other preparation may be placed inside this period.

# 11. Attendance Selection Guidance

Codex should not blindly attend every available class.

Its job is to choose the minimum sensible attendance pattern that approximately satisfies the user's preferred **20% per active subject** target while protecting preparation quality.

Practical interpretation:

- **IWT:** the mandatory Monday lab already contributes significant attendance and may be sufficient for the planning window.
- **Computer Vision:** aim to attend at least one suitable CV class if needed to satisfy the attendance preference.
- **Recommendation Systems:** aim to attend at least one suitable RecSys class if needed.
- **EPQ:** aim to attend at least one suitable EPQ class if needed.

Do not add extra attendance merely for symmetry.

Choose the class that causes the least disruption to:

- high-value LSEG preparation;
- mandatory midsem self-study;
- project sessions;
- DSA;
- LSEG OA work;
- final verification;
- Sep 16 final mock.

---

# 12. Class Attendance Does Not Replace Self-Study

This rule is important enough to repeat:

> A class is not a study block.

For example:

- attending CV from 12:00 PM–1:00 PM does not satisfy that day's mandatory midsem self-study block;
- attending RecSys does not replace a RecSys revision block;
- attending EPQ does not count as EPQ revision;
- attending IWT Lab does not replace IWT exam preparation.

The planner must keep attendance and actual preparation separate.

---

# 13. Scheduling Around Classes

When a class is selected for attendance:

- label it explicitly;
- preserve travel/transition realism if needed;
- do not pretend the class itself advances the planned revision workload;
- avoid placing an intense study block in an impossible transition window immediately before/after it if the logistics make that unrealistic.

Codex may use nearby short gaps as rest/buffer if that produces a better day.

---

# 14. Weekend Usage

Saturday and Sunday contain no class constraints.

Codex should treat these as the most flexible and valuable long preparation days.

They are suitable for:

- long full-revision blocks;
- DSA;
- project revision/questionnaire sequencing;
- LSEG OA preparation;
- technical tracks that need uninterrupted time;
- meaningful midsem coverage.

However, the planner must still include meals and realistic rest/buffer periods.

---

# 15. Final-Day Constraint

Wednesday, 16 September is the final full preparation day.

The day should increasingly favour:

- consolidation;
- final verification;
- LSEG-specific review;
- project/HR/resume readiness;
- DSA readiness;
- final midsem maintenance;
- the mandatory night mock.

Heavy new content should be avoided late in the day unless unavoidable.

The planner must preserve enough mental energy for the night mock.

---

# 16. If the Official Midsem Timetable Arrives

The exact midsem exam order is not yet known.

The only confirmed fact is:

- **midsems begin 18 September 2026**.

If the official exam timetable is added later, Codex may use it to adjust the **relative emphasis of midsem blocks**, especially on 15–16 September.

It must not discard already approved planning decisions without explaining why the new timetable materially changes the optimal schedule.

---

# 17. Hard Constraints Summary

The following are non-negotiable:

- Planner dates: **10–16 September 2026**
- Prep starts no earlier than **9:00 AM**
- Prep ends by **10:30 PM**
- Lunch: **1:00–2:00 PM**
- Dinner: **7:30–8:30 PM**
- At least **one genuine midsem self-study block every day**
- Class attendance does **not** count as study
- Monday IWT Lab is **mandatory**
- Friday **12:30–3:00 PM** is reserved for namaz
- Blockchain, EMC, and TW classes are treated as **not happening**
- Aim for approximately **20% attendance per active subject**
- Codex chooses optional classes to minimize disruption
- Rest/buffer blocks must exist
- Sep 16 night must preserve the mandatory final mixed LSEG mock
